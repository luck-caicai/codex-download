添财AI · Codex 简体中文设置（Windows）

适用范围
适用于通过微软商店或 MSIX 安装包安装的 Codex，无需管理员权限。

使用步骤
1. 解压整个压缩包，不要直接在压缩包里运行脚本。
2. 结束 Codex 中正在进行的任务，并保存文件。
3. 双击 codex-zh-cn.bat。
4. 在弹出的窗口中输入 Y，再按回车。
5. 脚本会关闭 Codex、备份并修改语言配置，然后尝试重新打开 Codex。
6. 看到“已设置为简体中文”后，按窗口提示关闭脚本窗口。

遇到问题
提示“未找到 Windows 版 Codex”：请先安装 Codex，再重新运行脚本。
没有自动重新打开：从开始菜单手动打开 Codex。
配置检查未通过：按脚本提示处理；脚本会保留原文件。
如不想继续，在确认时输入其他内容即可取消。

脚本做了什么
将用户目录下 .codex\config.toml 中的语言字段设为：
[desktop]
localeOverride = "zh-CN"

如果设置过 CODEX_HOME，则使用该目录下的 config.toml。
这是启用 Codex 内置的简体中文界面，其他配置会保留。
再次运行不会重复添加语言字段。旧版或未来版本可能使用不同设置；不支持时请通过 Codex 自带的语言选项调整。

备份与恢复
原配置存在且需要修改时，会在同一目录生成备份：
config.toml.before-zh-cn.时间标识.bak

如需恢复，先退出 Codex，再把需要的备份复制为 config.toml，随后重新打开 Codex。

重启说明
脚本先请求关闭窗口；确认继续后，如有同一个 Codex 应用的进程仍未退出，会将其结束。因此请务必先结束任务、保存文件。

验证范围
配置修改、备份和重复运行已使用独立文件验证；自动退出和重新打开流程尚未实机验证。
