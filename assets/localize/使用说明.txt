添财AI · Codex 简体中文设置

先结束 Codex 中正在进行的任务并保存文件。运行后输入 Y 确认，脚本会备份配置、设置简体中文，然后尝试重新打开 Codex。

Windows
解压整个 Windows 压缩包，双击 codex-zh-cn.bat。适用于官方商店 / MSIX 安装的 OpenAI.Codex，无需管理员权限。

Mac（M 系列、Intel 共用）
解压整个 Mac 压缩包，双击“启动中文设置.command”。它会调用同目录的 codex-zh-cn.sh，请把两个文件保存在一起。
也可以打开“终端”，输入 sh 和一个空格，把 codex-zh-cn.sh 拖进终端，再按回车。不依赖 Python、Node.js 或 Homebrew。
需要先把 Codex 安装到“应用程序”。脚本按 com.openai.codex 标识识别应用，也兼容应用名称变为 ChatGPT 的该桌面版本。

脚本修改的位置
Windows：用户目录下的 .codex\config.toml
Mac：~/.codex/config.toml
如果设置过 CODEX_HOME，则使用该目录下的 config.toml。

只设置以下语言字段，其他配置保留：
[desktop]
localeOverride = "zh-CN"

这是启用 Codex 内置的简体中文界面，不是替换程序文件的翻译补丁；不改变模型、接口地址、API Key、账户或权限设置。
配置键已核对本机 Windows Codex 26.903.9818.0 的实现。旧版或未来版本可能使用不同设置；不支持时请通过 Codex 自带的语言选项调整。

备份与恢复
首次有改动时，原文件会备份到同一目录，文件名为 config.toml.before-zh-cn.时间标识.bak。
如需恢复，先退出 Codex，再把需要的备份复制为 config.toml，随后重新打开应用。
再次运行不会重复添加 [desktop] 或语言字段。
遇到符号链接、重复语言字段、desktop 内联表或不完整的配置，脚本会停止并保留原文件。

重启方式
Windows 先请求关闭窗口；确认继续后，如有同一个 Codex 应用的 GUI 进程仍未退出，会将其结束。不会按 codex.exe 名称批量结束命令行进程。
Mac 请求应用正常退出；如果应用未退出，停止操作并提示手动退出。
自动打开失败时，请从开始菜单或“应用程序”手动打开 Codex。

验证范围
配置修改、备份、重复运行和特殊文本处理使用独立测试文件验证；没有改动开发者正在使用的配置或结束当前 Codex。
Mac 的 shell 语法和配置处理逻辑已做检查；当前环境是 Windows，尚未在真实 Mac 上验证退出、重开和双击流程。
