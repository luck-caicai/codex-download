添财AI · Codex 中文显示修复 3.0（Mac）

使用步骤
1. 请先安装与芯片匹配的原版 Codex / 新版 ChatGPT，结束任务并保存文件。
2. 解压下载的 ZIP，里面只有“修复中文显示.command”一个文件。M 系列与 Intel 通用。
3. 双击它，等待自动完成修复并重新打开 Codex，无需输入 Y。
4. 以后使用桌面的“Codex 中文修复版（添财AI）.command”。

所有修复代码已合并在这个文件中，不需要额外的 .sh 或 JS 文件。
正常运行只显示三个进度步骤，成功后自动结束，不再等待按回车；终端窗口是否自动关闭取决于系统设置。
如果发现多份安装或没有自动找到应用，会弹出选择窗口，请选择已安装的原版 Codex / 新版 ChatGPT，不要选择修复副本或 DMG 安装包。

双击打不开时
1. 打开 Mac 的“终端”。
2. 输入 sh，再输入一个空格。
3. 把“修复中文显示.command”拖进窗口，按回车即可运行。
不要使用 sudo，也不需要关闭系统安全设置。

运行前须知
工具保留原安装，在当前用户目录创建独立副本，需预留约 2 GB 空间。
工具会请求 Codex 正常退出，备份语言配置并重新打开。无法正常退出时会停止，不强制结束进程；请手动退出后重试。
副本使用独立界面数据目录，可能需要重新登录；CODEX_HOME 仍指向原来的配置目录，工具不会搬移或删除会话。
优先使用应用内置的 Node.js，不会下载安装开发环境。

本机签名说明
Mac 修复副本采用本机临时签名，不再具有 OpenAI 原厂签名，可能需要重新登录或授予系统权限。
原厂推送、共享钥匙串等系统集成功能可能受影响；如有异常，可从原入口使用原版。
工具保留原来的内置完整性校验状态，不修改原应用。未知代码结构、额外摘要校验或签名验证不通过时会停止。

失败时如何反馈
将终端错误与最新诊断记录发到交流群。
Finder 中按 Command + Shift + G，粘贴下面的目录：
~/Library/Application Support/TiancaiAI/CodexLocale/
打开最新的 repair-mac- 开头的 TXT 文件。
诊断记录包含版本、路径、失败阶段和结果，不记录完整配置、聊天内容或账号密钥。
提示缺少内置 Node.js：更新与本机芯片匹配的原版安装包后再试。
提示原始签名或资源不匹配：重新安装原版后再试，不要选择他人修改过的副本。

恢复与更新
从“应用程序”可打开原版 Codex / ChatGPT。
原版升级后，请先退出修复版，再运行脚本创建新版副本。
副本位于 ~/Library/Application Support/TiancaiAI/CodexChinese/build-时间-标识/。
退出后可手动删除不再使用的旧 build- 目录与启动入口；不要删除 .codex 配置目录。
原配置需要修改时会在同目录生成 config.toml.before-zh-cn.时间标识.bak。
如需恢复，先退出 Codex，将所需备份复制为 config.toml，再重新打开。
