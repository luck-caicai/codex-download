添财AI · Codex 中文设置与显示修复 2.0（Mac）

适用范围
Mac 的 M 系列芯片和 Intel 芯片通用。请先安装与芯片匹配的原版 Codex / 新版 ChatGPT。

已经选了中文，页面仍是英文：使用“修复中文显示.command”
1. 解压整个压缩包，保留其中全部文件。
2. 结束 Codex 中的任务，并保存文件。
3. 双击“修复中文显示.command”。
4. 脚本会寻找已安装的原版应用；发现多份时，请在弹窗中选择原版 Codex / 新版 ChatGPT，不要选择修复副本。
5. 核对版本、位置、空间占用和本机签名说明，输入 Y，再按回车。
6. 等待复制、修补和签名完成。脚本会退出 Codex，备份并设置语言配置，然后打开修复副本。
7. 检查界面是否显示中文。以后请双击桌面的“Codex 中文修复版（添财AI）.command”。

Mac 显示修复工具的原理
在 ~/Library/Application Support/TiancaiAI/CodexChinese/build-时间-标识/ 创建一份应用副本。
仅在副本中启用受支持的内置翻译开关，更新资源哈希和启动环境，再使用 macOS 自带工具为副本创建本机临时签名。
应用原本已带有中文翻译，工具不另外下载语言包。原安装保留，额外空间占用在运行前显示。
副本使用独立的界面数据目录 CodexChinese/UserData，可能需要重新登录。
脚本优先使用应用内置的 Node.js；不会下载依赖，不要求安装 Python 或 Homebrew。

本机签名说明
修改后的副本不再具有 OpenAI 原厂签名。
工具保留原来的内置资源校验开关，不关闭系统 Gatekeeper 或 SIP，不修改原应用。
为本机签名调整副本的签名权限后，原厂推送、共享钥匙串或部分系统集成功能可能受影响，也可能需要重新授权。
如这些功能异常，请从原来的入口打开原版。新版额外摘要校验、未知代码结构或签名验证不通过时，工具会停止处理。

显示修复后的恢复与更新
恢复使用原版：直接从“应用程序”打开原来安装的 Codex / ChatGPT。
原版升级后，请退出修复版，重新运行工具创建新版副本。旧副本不会自动变成新版。
退出修复版后，可手动删除不需要的 build-开头目录和对应启动入口；不要删除整个 .codex 配置目录。

显示修复的诊断记录
修复失败、启动后仍是英文或无法打开时，请保留终端错误和最新诊断记录，发到交流群。
目录：~/Library/Application Support/TiancaiAI/CodexLocale/
Finder 中按 Command + Shift + G，粘贴这个目录即可打开，查看最新 repair-mac-开头的 txt。
记录包含版本、路径和结果，不记录完整配置、聊天内容或账号密钥。
提示缺少内置 Node.js：更新与本机芯片匹配的原版安装包后再试。
提示原始签名、资源或哈希不匹配：重新安装原版后再试，不要选择别人修改过的副本。
提示应用未退出：手动退出后重新运行，工具不会强制结束正在工作的应用。

普通中文设置：使用“启动中文设置.command”
1. 解压整个压缩包。
2. 把“启动中文设置.command”和 codex-zh-cn.sh 保存在同一个文件夹里。
3. 结束 Codex 中正在进行的任务，并保存文件。
4. 双击“启动中文设置.command”。
5. 核对终端显示的应用版本、应用位置和配置文件，输入 Y，再按回车。
6. 脚本会退出 Codex、备份并修改语言配置，然后尝试重新打开 Codex。
7. “语言配置已写入”表示配置保存成功；请查看重开的 Codex 是否已经显示中文，再按回车结束脚本。

双击打不开时，也可以通过终端运行
1. 打开 Mac 的“终端”。
2. 输入 sh，再输入一个空格。
3. 显示修复：把“修复中文显示.command”拖进终端窗口，再按回车。普通设置：拖入 codex-zh-cn.sh。
4. 按提示输入 Y 并回车。

请保留同目录的 .sh 和 .cjs 文件。不要使用 sudo，也不需要关闭系统安全设置。

遇到问题
设置中已选“简体中文”，页面却仍是英文：打开 Settings > General > Language，先选 English，再选“简体中文”。
如果手动切换后整页能变中文，说明中文翻译可用，不需要另装语言包；请再退出、打开 Codex，确认中文能否保留。
提示“未找到 Codex”：请确认 Codex 已安装到“应用程序”。
提示 Codex 未能正常退出：手动退出 Codex 后重新运行脚本。
提示无法确认运行状态：脚本不会写入配置，请手动退出 Codex 后重试。
没有自动重新打开：从“应用程序”手动打开 Codex。
配置检查未通过：按脚本提示处理；脚本会保留原文件。
如不想继续，在确认时输入其他内容即可取消。
需要协助时，请保留终端里显示的应用版本、应用位置和错误提示，发到交流群。

普通设置脚本做了什么
将 ~/.codex/config.toml 中的语言字段设为：
[desktop]
localeOverride = "zh-CN"

如果设置过 CODEX_HOME，则使用该目录下的 config.toml。
这会设置 Codex 内置界面的语言偏好，其他配置会保留。脚本不修改应用程序文件，不安装额外语言包。
再次运行不会重复添加语言字段。旧版或未来版本可能使用不同设置；不支持时请通过 Codex 自带的语言选项调整。

备份与恢复
原配置存在且需要修改时，会在同一目录生成备份：
config.toml.before-zh-cn.时间标识.bak

如需恢复，先退出 Codex，再把需要的备份复制为 config.toml，随后重新打开 Codex。
